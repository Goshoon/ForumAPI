<h1><b>Full-Stack Forum System</b></h1>

A complete forum platform consisting of a RESTful API, a web interface, and a desktop application, designed for creating and sharing thread-based forum posts.

---

<b><h2>Features</h2></b>
<ul>
    <li>Thread-based discussion system with posts and replies</li>
    <li>RESTful API for communication between clients and server</li>
    <li>Web application and desktop application clients</li>
    <li>Server-side data handling and persistence</li>
    <li>Modular architecture separating API, web, and application layers</li>
</ul>

---

<h2><b>Usage</b></h2>

1. Run the RESTful API to enable communication with the server (by default it runs on <code>localhost</code>).
2. Open either the desktop application or the web application.
3. Interact with the forum by creating threads and posting messages through the client interfaces.

---

<b><h2>Build</h2></b>

<b>API</b><br>
The API handles communication with the server over HTTPS.

- Navigate to the API directory.
- Create and activate a virtual environment.
- Install dependencies using the provided <code>requirements.txt</code> file.
- Run the API server.

<b>Application</b><br>
The desktop application is built using Visual Studio.

- Open the solution file in Visual Studio.
- Build and run the project using the default configuration.
